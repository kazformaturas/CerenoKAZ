## Provenance

The methodology in this skill is derived from an open-source Next.js animation
starter published by Textura Agency (`textura-agency/next16-claude-starter`),
released under **the Unlicense** — a public-domain dedication that imposes no
attribution requirement. Credit is given here because the derivation is real,
not because it is compelled.

What was taken: the architecture of the animation system (one shared render
loop, spring-based motion, the trigger-position grammar, the rem-based adaptive
grid, the three-tier token convention) and its documented failure modes.

What is original to this skill: the measured spring characterisations (damping
ratios, t95 and settle times), the font-metric measurements behind the leading
floor, the geometric-decay analysis of the canvas brush, the zero-dependency
implementations of the spring stepper and ticker, and the pre-flight
verification procedure.

All measurements in this skill were produced by executing the code against real
data, not quoted from the source material — including where doing so contradicted
it.
